# 가쿠로 도우미

가쿠로 문제를 풀면서 막힐 때 다음 한 단계를 힌트로 알려주는 PWA. 브라우저에서 쓰거나 휴대폰 홈 화면에 앱으로 설치할 수 있고, 설치 후에는 오프라인에서도 동작한다.

**사용하기**: https://itjeong-dev.github.io/KakuroHelper/ · 함께 쓰는 앱: [스도쿠 도우미](https://itjeong-dev.github.io/SudokuHelper/) · [노노그램 도우미](https://itjeong-dev.github.io/NonogramHelper/) · [지뢰찾기 도우미](https://itjeong-dev.github.io/MinesweeperHelper/)

## 규칙

가로·세로로 이어진 흰 칸에 1~9를 넣는다. 검은 칸의 대각선 위쪽 숫자는 오른쪽으로 이어진 흰 칸의 합, 아래쪽 숫자는 아래로 이어진 흰 칸의 합이다. 한 줄 안에는 같은 숫자를 두 번 쓸 수 없다.

## 기능

- **랜덤 문제**: 판 크기(6×6·8×8·10×10·12×12, 단서 칸 포함)와 난이도를 골라 새 문제를 푼다. 모든 문제는 답이 하나이고, 찍지 않고 논리로 끝까지 풀린다. 난이도는 풀 때 꼭 필요한 가장 어려운 기법으로 나눈다.
  - 하: 마지막 한 칸·가로세로 조합 겹치기
  - 중: 꼭 들어갈 숫자·조합 좁히기
  - 상: 숫자 쌍·칸마다 맞춰 보기
  - 최상: 숫자를 넣어 보고 모순 찾기
  - 고른 크기·난이도는 기억해 두고, 푸는 중에 `같은 조건으로 다시`로 이어서 푼다. `새 게임`은 크기·난이도를 다시 고른다
- **조합 도움말**: 칸을 고르면 그 칸이 지나는 가로·세로 줄의 합을 만드는 조합을 보여준다. 이미 넣은 숫자를 포함하는 조합만 남긴다.
- **숫자·후보수 입력**: 숫자를 넣으면 같은 줄 칸의 후보에서 그 숫자를 자동으로 지운다(끌 수 있음). `후보 채우기`는 조합으로 가능한 숫자를 모든 빈칸에 적는다.
- **오류 표시**: 같은 줄에 같은 숫자가 있거나, 넣은 숫자의 합이 단서를 넘거나 다르면 빨갛게 표시한다.
- **단계별 힌트**: 힌트를 누를 때마다 한 단계씩 더 알려준다.
  1. 어디를 볼지 (줄 강조)
  2. 무엇을 찾을지 (기법)
  3. 칸과 이유. `판에 적용`으로 반영한다.
- 진행 상태는 브라우저에 자동 저장된다.
- 새 버전이 배포되면 화면 아래에 새로고침 안내가 뜬다.

### 힌트 순서

틀린 숫자·같은 줄 중복·합이 맞지 않는 줄 → 빠진 후보 → 마지막 한 칸 → 가로·세로 조합 겹치기 → 후보가 하나 남은 칸 → 꼭 들어갈 숫자 → 조합 좁히기 → 숫자 쌍(세 쌍) → 칸마다 맞춰 보기 → 넣어 보고 모순 찾기 → 정답 공개.

## 키보드

| 키 | 동작 |
|---|---|
| 1~9 | 숫자 입력 (Shift+숫자: 후보) |
| Space, N | 숫자/후보 전환 |
| 방향키, Tab / Shift+Tab | 칸 이동 (검은 칸은 건너뜀) |
| Backspace, Delete | 지우기 |
| H | 힌트 |
| Ctrl+Z | 실행 취소 |

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm test          # 풀이·힌트·문제 만들기 테스트
npm run build     # dist/에 PWA 빌드
npm run icons     # public/icon-192.png, icon-512.png 다시 만들기
```

main에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 배포한다.

## 구조

- `src/kakuro/board.ts`: 판·줄 정보, 합 조합표, 조합으로 가능한 후보
- `src/kakuro/solver.ts`: 줄 단위 추론(단계별 규칙, 칸마다 맞춰 보기)과 답 세기
- `src/kakuro/hints.ts`: 힌트 엔진 (`findHint`, `applyHint`)
- `src/kakuro/generate.ts`: 랜덤 문제 만들기 (흰 칸 배치 → 숫자 채우기 → 정한 단계 기법으로 끝까지 풀리게 숫자 고치기 → 난이도 맞추기). 화면이 멈추지 않게 `generate.worker.ts`에서 돌린다
- `src/components/AppNav.tsx`: 퍼즐 도우미 앱 모음 (네 앱에 같은 파일)
- `src/components/SolvedToast.tsx`: 판 위에 겹치는 안내(다 풀었을 때 등) (네 앱에 같은 파일)
- `src/components/UpdateBanner.tsx`: 새 버전 새로고침 안내 (네 앱에 같은 파일)
- `src/App.tsx`, `src/components/`: 화면
